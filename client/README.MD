# DeploySarthi — Client

React frontend for the DeploySarthi platform.

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- React Router
- Axios
- Recharts
- Framer Motion
- Sonner
- Lucide React

## Requirements

- Node.js 20+
- npm

## Setup

```bash
npm install
cp .env.example .env
```

## Environment

```env
VITE_API_URL=http://localhost:5000/api
VITE_WS_URL=ws://localhost:5000
```

## Run

```bash
npm run dev
```

Frontend: `http://localhost:5173`

## Main Features

- Dashboard
- Project management
- Deployment monitoring
- Incident monitoring
- AI investigation chat
- Readiness checks
- Public project gallery
- Telegram alerts
- Real-time updates
